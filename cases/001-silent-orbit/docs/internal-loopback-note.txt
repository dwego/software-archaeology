SUBJECT: INTERNAL TELEMETRY LOOPBACK TEST

The communication subsystem includes an internal loopback mode used
during firmware development.

In loopback mode, telemetry frames generated by the flight encoder
are routed directly to the onboard diagnostic decoder.

The test verifies:

- frame generation
- checksum generation
- payload integrity
- encoder/decoder compatibility

The onboard diagnostic decoder is built from the same communication
software revision as the flight encoder.

The loopback path does not include:

- GDU-4 ground equipment
- external radio transmission
- ground communication interfaces

A successful loopback result therefore confirms internal software
compatibility only.

It must not be treated as a substitute for end-to-end ground testing.

-- L. Mercer
Flight Software Group
