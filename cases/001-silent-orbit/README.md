# Case 001 — Silent Orbit

**Difficulty: Medium**

**November 1968**

The Astra Research Directorate is preparing **ORPHEUS-3**, an experimental orbital platform designed to evaluate a new onboard computer and communication subsystem.

During final ground testing, the spacecraft begins exhibiting two communication failures.

Telemetry frames received by the ground station are intermittently rejected.

At approximately the same time, the primary radio channel fails to acquire a stable ground lock.

No communication hardware was replaced between the last successful test and the first failed test.

The flight software, however, was recently modified.

Several technical documents, test records, engineering memoranda, and software revisions have been recovered from the project archive.

Some of the recovered material appears to disagree.

## Assignment

Reconstruct the ORPHEUS-3 communication incident.

Your investigation should determine:

- what caused the telemetry failure
- what caused the radio configuration failure
- which change introduced the incident
- which system behavior was actually expected
- why the failures were not detected before the ground test
- what corrective action is required

## Recovered System

The recovered archive contains material from the ORPHEUS-3 communication subsystem.

Information may be incomplete, outdated, contradictory, or based on assumptions that were valid only at a particular point in the project.

## Investigation Rules

There are no hidden flags.

There is no single file containing the complete answer.

A suspicious line of code alone is not enough to complete the case.

Your conclusion should be supported by evidence from the recovered system.
