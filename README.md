# Software Archaeology

Software Archaeology is a collection of fictional legacy software systems designed to be investigated.

Each case contains a recovered system along with source code, documentation, records, and other artifacts from its history.

Your task is to reconstruct what happened, identify the failures, and support your conclusions with evidence.

Not every artifact should be assumed to be correct.

Some information may be outdated, incomplete, misleading, or inconsistent with the system that was actually deployed.

## Difficulty

Cases are classified using three levels:

* **Easy** — focused investigation with relatively direct evidence
* **Medium** — requires connecting evidence across multiple parts of the system
* **Hard** — larger investigations with incomplete, misleading, or deeply buried evidence
